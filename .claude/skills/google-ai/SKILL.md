# Google AI Integration (Gemini)

This skill guides you through adding Google's Generative AI capabilities to the AlgoViz template. It covers both the Google AI SDK (Cloud-based Gemini) and Gemini Nano (On-device AICore).

## 1. Setup Dependencies

Add the Google AI SDK to `app/build.gradle.kts`:

```kotlin
dependencies {
    // Google AI SDK for Gemini (Cloud)
    implementation("com.google.ai.client.generativeai:generativeai:0.9.0")
    
    // Optional: Android AI Client for Gemini Nano (On-device)
    // implementation("androidx.ai:ai-client-generative:0.1.0-alpha01")
}
```

## 2. Implement the AI Service

Create `app/src/main/kotlin/com/mariocjun/algoviz/ai/AiService.kt`. This service should handle communication with the model.

**Example for Gemini API:**

```kotlin
class AiService(apiKey: String) {
    private val model = GenerativeModel(
        modelName = "gemini-1.5-flash",
        apiKey = apiKey
    )

    suspend fun explainAlgorithm(name: String): String {
        val prompt = "Explique brevemente o algoritmo de ordenação $name de forma didática para um desenvolvedor Android."
        return model.generateContent(prompt).text ?: "Erro ao gerar explicação."
    }
}
```

## 3. Recommended Integration Points

- **Profiler (MainActivity):** Use AI to analyze benchmark results. Send the JSON output of a benchmark to Gemini and ask for an interpretation of the cache latency or throughput bottlenecks.
- **Sort Visualizer (VizActivity):** Show an AI-generated explanation of the current algorithm's time and space complexity.
- **Códex (DocsActivity):** Use AI to help map the project's quality against the ISO 25010 standard.

## 4. API Key Security

**Never** commit your API key to version control. Use `local.properties` or a dedicated `secrets.properties` (gitignored) and load it at runtime or via `buildConfig`.

## 5. UI/UX Guidelines

- Use a distinct AI icon (e.g., `Icons.Default.AutoAwesome`).
- Show a loading state (e.g., `LinearProgressIndicator`) while the model is generating.
- Use a typewriter effect or a clear "Generated by AI" disclaimer.
